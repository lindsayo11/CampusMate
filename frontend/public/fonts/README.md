# Campus Sans

Noto Sans SC from Google Fonts, regular (400) and semibold (600), served locally as WOFF. The full character set is included so project names and Chinese document drafts remain readable on systems without installed CJK fonts. Each font contains 30,890 mapped characters. Characters outside this coverage fall back to device fonts.

Distributed under the SIL Open Font License 1.1; see OFL.txt. ui-characters.txt records an earlier subset.
