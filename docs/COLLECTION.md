# 内容采集与附件解析

管理员入口 `/admin/collector`。先配置已获准使用的公开来源，再通过 Worker 定时采集；也可上传已取得的 HTML、文本型 PDF、XLSX 或 UTF-8 文件。解析结果进入私有原文归档，管理员核对结构化字段后提交既有人工审核流程。采集成功不会直接发布机会。

## 启动和配置

在 API 和 Worker 设置 `COLLECTOR_ALLOWED_HOSTS=就业网完整域名,学院网完整域名`，只匹配完整主机名，不匹配通配符/子域名。Compose 已透传该变量。默认空值拒绝所有自动联网采集，文件导入不受此白名单限制（不发出网络请求）。
运行数据库升级 `alembic upgrade head`，迁移头为 0010，然后启动 `python -m app.worker`。Worker 每轮先投递提醒，再调度到期来源并执行一个采集任务，轮次间隔 30 秒。最短来源间隔 60 分钟。页面“立即采集/重跑”只排队，不在 HTTP 请求内抓取网站。

## 网络和解析边界

只接受 HTTPS 443、无账号密码的白名单 URL。域名解析到内网/回环/保留地址会拒绝；请求固定已验证的公网 IP，并用原始 Host 和 TLS SNI 校验证书。重定向逐跳复核，访问页面前检查 robots.txt。robots 的 404 视为未提供策略，其他 HTTP 错误导致失败；不会跳过 robots 禁止或登录墙。配置的网络代理仍被尊重。

只抓取明确配置的单页/单个附件，不自动遍历栏目、不执行网页 JS、不下载页面所有链接。页面型适配优先提取 article/main，其次 body；具体官网可能需要后续专用 adapter。公开源授权依据由管理员填写，不能把通过白名单当作获得来源许可。

文件最大 4 MiB，正文最大 200000 字符。解析在子进程中执行，30 秒超时；支持 POSIX 资源限制的主机额外限制 512 MiB 地址空间/20 秒 CPU。PDF 最多 100 页，无文本的扫描件提示人工 OCR；不提供 OCR。Excel 最多 20 表/5000 行/100 列，检查 ZIP 解压体积；公式不求值也不采信缓存值，标为人工核对；不支持 XLS/宏工作簿。
原文归档保存提取后的文本、SHA-256、版本链和采集时间；运行记录保存原文件字节 SHA-256，当前不长期保存原始 PDF/XLSX 二进制，运营方应自行保留获准原件。

## 重试和审核

任务状态 queued → running → succeeded/unchanged；失败后最多 3 次尝试，重试间隔 60/120 秒。5 分钟租约到期可由 Worker 回收，完成时校验领取令牌，旧 Worker 不能覆盖新任务结果。重复排队返回同一活跃任务。最终失败后可手动重跑；停用来源后不再计划新采集。

解析文本变化才生成新归档版本。已归档文本可反复整理为不同审核条目；相同原文和字段去重。提交历史版本不会把当前版本指针回退。资格规则 evidence 必须出现在该版本原文中；发布时间、截止时间等业务字段仍由管理员核对，不从文件名或模型猜测。

## 验证边界

自动测试覆盖 HTML/PDF/XLSX 实际解析、大小/扫描件拒绝、robots 拒绝、地址限制、固定 IP/SNI、重定向拒绝、重试/去重、租约回收并发、归档到审核及权限。网络使用 MockTransport/测试响应，不宣称真实官网已适配。正式运行需首发学校与获准官方 URL，并在目标网络做实际采集验收。
