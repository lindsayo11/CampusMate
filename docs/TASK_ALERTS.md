# 队伍任务到期通知

任务设置负责人和截止时间后，Worker 会为截止前 24 小时内或已经逾期的未完成任务生成站内通知。通知中心 `/notifications` 可查看任务提醒、标为已读、分页，并跳转到对应队伍。不开启邮件、短信或第三方推送。

通知幂等键包含任务 ID、负责人和 UTC 截止时间。多 Worker 并发采用队伍/房间现有锁顺序，数据库唯一键防重复。仅改标题、描述或 todo/doing 状态不重复提醒；改截止日期或负责人会产生新的有效提醒。

只向当前队伍成员中的负责人投递。列表每次按当前状态校验：已完成/取消、退出/被移除、队伍解散、负责人或截止时间变化的旧通知不会显示，也不能继续标记。旧记录保留在数据库用于防重复，不含任务正文快照；页面显示当前任务标题。

接口：GET /v1/task-alerts 支持 before 游标，每页 50 条；POST /v1/task-alerts/{id}/read 仅本人且通知仍有效时可操作。前端提供手动刷新。

新增迁移 0012。执行 alembic upgrade head 并重启 API/Worker 后生效。

自动测试覆盖两 Worker 并发去重、本人/跨账号已读权限、退出撤销可见性、改期到远期、改为逾期、转交、完成和解散。生产 PostgreSQL 与真实用户体验仍需单独验收。
