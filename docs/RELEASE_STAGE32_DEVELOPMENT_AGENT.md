# Stage32 学生发展规划助手

版本：v0.32.0-agent.1。依据用户提供《CampusMate 平台智能体开发方案文档 V1.0》增量开发。保留既有平台及Stage31数据规则；不是已经完成真实模型和生产环境验收的正式版本。

## 使用

解压后从项目根目录运行 `bash scripts/start_retained_demo.sh`，访问 `http://127.0.0.1:3000/agent`。该启动方式自动开启助手入口，使用独立演示数据库。其他部署设置 `ENABLE_AGENT_UI=true` 并迁移到0023。不开启UI不影响既有业务。

未配置模型时显示规则模式，可实际查询业务数据、生成模板准备计划、确认写入、更新计划及创建提醒。配置模型后，模型识别工具参数并提供基于工具结果的自然语言解释。服务配置缺失不伪装为大模型模式。

## 与方案对应

| 方案能力 | 本版实现 | 边界 |
| --- | --- | --- |
| 用户画像与路径咨询 | 读取当前身份画像和路径目录，支持考研、保研、考公、就业、留学、创业关键词 | 规则模式提供可比较路径，不声称个性化预测成功率 |
| 事项搜索 | 复用当前可展示的数据中心，按关键词、路径、地区查询，最多10条 | 没有数据不会编造；当前不支持完整的学历/专业结构化筛选 |
| 条件匹配 | 与原机会资格模块共用确定性规则求值，读取当前发布版本证据 | 仅支持已核验的等值、包含等规则；未知操作符/复杂逻辑返回信息不足 |
| 个人规划 | 根据目标路径Timeline生成阶段计划，无节点时给4步准备模板 | 准备建议不等于官方日程，不推测官方日期；尚无模型自由生成整套规划的工具参数 |
| 任务管理 | 计划预览、确认保存到UserPlan、查询及状态更新 | 个人任务统一复用UserPlan；不额外复制核心业务数据 |
| 提醒 | 计划提醒、Worker投递、已读与取消、个人通知页 | 站内提醒；用户必须提供明确未来时间；不自动发送外部邮件 |
| 材料辅助 | 简历、个人陈述、推荐信、计划书的结构建议；模型配置后辅助解释与建议 | 无模型时是检查清单；不编造经历或代替正式证明 |
| 会话 | 私有持久会话、最近历史、有限上下文继承、删除 | 规则模式仅支持明确指代字段继承；不是无限长期对话记忆 |
| 知识增强 | 当前公开证据分段、本地稀疏文本向量余弦检索、原文URL/位置/hash，并保留旧知识库检索 | 不是语义嵌入模型；无生产向量数据库及大规模索引，不宣称第四阶段全部完成 |

新API位于 `/v1/development-agent`，新页面替换原行动助手页面。旧 `/v1/agent` API保留兼容，避免破坏之前的工具调用。

## 业务一致性

写操作以AgentAction保存预览，10分钟内确认有效。确认时重新核对归属、当前状态和日期；并发/重复确认返回相同结果，不重复创建计划。过期、取消、删除会话后的待确认操作不能执行。删除会话保留已生成的业务计划。

会话只存问题、工具结果与动作引用；用户身份来自鉴权，不接受模型指定user_id。提醒由同一个Worker执行。检索每次复核发布可见性，被删除或撤回的数据不再进入新答案依据。

模型输入包括当前问题、有限历史与本次工具结果。只有配置的服务会接收这些内容；密钥仅在服务端。模型文字属于辅助解释，资格和日期以工具结果与原文为准，不能承诺模型绝无错误。模型没有删除、管理员、外部发信或任意SQL工具。

## 模型接入

新助手使用独立配置 `DEVELOPMENT_DIFY_API_BASE` 和 `DEVELOPMENT_DIFY_APP_KEY`，避免误用旧六工具工作流。Docker配置已转发到后端。详细工作流契约见 `dify/DEVELOPMENT_ASSISTANT.md`，JSON输入schema见 `specs/development-agent-request.schema.json`。

两项均为空时运行规则模式；配置模型后服务失败返回502，不静默把模型写请求转成其他操作。没有在本轮创建或部署外部Dify服务，也没有真实API密钥，因此真实推理质量、响应延迟和费用未验收。

## 保留的演示数据

独立库 `demo-data/retained-demo.db` 保留5人、3条模拟发布、30条个人计划、15条订阅、5个Agent会话和10轮会话记录。其中15条计划是本轮通过Agent确认动作新增。没有伪造真实运营用户。

模拟账号沿用 `demo-five-people-20260929-student-1` 至 `-5`。后台默认管理员与这些学生的会话隔离；并未新增网页一键切换身份。可使用受控演示请求头访问，禁止将演示身份机制公开部署。

新增复跑脚本 `scripts/seed_retained_agent.py`，只允许专用演示库，已存在的同名会话不会重复生成。删除自己的会话可在助手页面操作；完全清理模拟记录仍可停止服务后删除专用演示库。正式共享库不得这样清理。

## 验证与未完成项

本轮103项后端业务测试通过（不含2项既有历史迁移测试），包含新增8项Agent测试；19项前端测试通过。模型路由与生成测试采用HTTP契约模拟，不能替代真实模型验收。最终前端类型检查与生产构建通过。开启助手后的API/Web/Worker冷启动通过，25个页面HTTP检查通过（含/agent）；SQLite共61张表备份恢复后逐表行数一致，Worker健康且到期通知重复运行不重复投递。独立Alembic schema check通过。构建过程中曾出现生成目录ENOTEMPTY错误，清理构建缓存后成功重建。

未完成：真实模型工作流部署与推理验收、语义向量库、真实官方数据源全面接通、浏览器交互验收、PostgreSQL和完整历史迁移异常处理。多Agent在方案中属于未来扩展，本轮按单Agent实现。
