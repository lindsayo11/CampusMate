# 当前开发状态 v0.19.0

本轮在 v0.16.0 上完成阶段 17–19，均逐阶段产出完整累计源码；当前主要功能优先，UI 保留可操作逻辑。

## 本轮新增
- 来源配置、单页/附件定时采集、HTML/PDF/XLSX/文本解析、失败重试、手动重跑、租约回收、原文去重和审核衔接。
- 原文切片、公开权限、按板块/机会检索、精确引用、版本/审核/下线/过期过滤、行动助手引用。
- 队伍任务到期通知、幂等投递、任务改期/转交/完成/退出后的动态可见性、已读和分页。

## 验证
48 项后端、15 项身份协议、TypeScript、生产构建、0012 迁移、历史审核回填通过；29 张 SQLite 表实际备份恢复所有行一致。
浏览器套件20项本轮未执行。此前执行器 Chromium 启动 SIGTRAP；本轮只将新页面作为可构建页面交付，不冒充真实浏览器已验收。
网络测试为受控响应；真实官网、身份/邮件、Dify、PostgreSQL、容器/TLS 仍需部署环境验收。
