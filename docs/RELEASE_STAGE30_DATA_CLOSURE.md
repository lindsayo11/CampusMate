# CampusMate Stage30：数据使用闭环

版本：v0.30.0-ingestion.1；日期：2026-09-29。累计源码，非生产 RC。

## 已实现

- 原始文件按文档版本归档、SHA256 校验、管理员下载；重复导入去重，新版本使旧发布失效。
- 校准依据包含 robots、条款、许可 URL/摘录及页面 SHA256。提交人与两名审核人分离；前端不再默认声明授权已通过。
- 导入、排队、调度、Worker 与发布共用来源授权检查。Worker 在 HTTP 前及提交前复核，过期租约不能写入，落库失败回滚部分实体并保留脱敏失败状态。
- 发布冻结结构化快照；规则、证据及政策关联需人工审核，再由两名独立管理员批准。停用来源、开放阻断、原文损坏或数据变化会隐藏发布。
- `/admin/data` 导入/证据/发布工作台；`/data` 关键词、路径、地区查询与分页；详情展示官方链接、证据、岗位、规则及 JSON 导出；`/data/timeline` 展示明确日期。
- 数据事项保存到个人计划；明确未来截止日期可设置站内提醒。Worker 支持去重投递、来源失效通知；用户只能读取/取消自己的订阅。取消订阅保留个人计划，不覆盖用户已有计划编辑。
- 公务员工作簿和教育政策进入统一事项体系。保留已有国内升学、事业单位、公共招聘、海外升学、创业政策适配器及此前平台功能。
- 修复独立 Worker 启动时的通知模型重复注册，将共享模型移出执行入口。

## 升级注意事项

执行 `alembic -c backend/alembic.ini upgrade head`，目标迁移 0021。
迁移会暂停全部既有端点调度，因为旧校准没有完整依据；必须补充依据、重新审核后显式启用。不会自动继续抓取。
历史文档若无原始文件归档，需重新导入真实原文；不可用摘要代替。导入成功只是草稿，不代表公开发布或线上校准完成。
Python 安装包使用 PEP440 版本 `0.30.0.dev1`，API/前端产品版本为 `0.30.0-ingestion.1`。

## 本轮实测

- `bash scripts/check.sh`：94 项后端测试、2 项开发进程监督测试、19 项前端测试通过；TypeScript 和 Next production build 通过。
- 包含迁移升级/降级/schema check、三方校准与发布隔离、原文损坏/测试文件/待审规则阻断、撤销隐藏、订阅所有权与幂等投递、Worker HTTP 前阻断和事务回滚。
- 独立 API、standalone Web、Worker 冷启动通过；24 个页面 HTTP 200，3 个不存在/冻结入口内容检查通过。不存在的机会页面使用流式 not-found 内容，HTTP 状态仍为 200，未声称全为 HTTP 404。
- 实际到期提醒运行两次只生成一次通知；SQLite 全部表备份恢复后逐表行数一致。
- Python editable package 安装通过。API 合约随打包更新。
- Playwright 列出 28 项桌面/移动端用例；本轮无法成功安装/启动 Chromium，浏览器交互及视觉验收未完成。HTTP 检查不替代浏览器验收。
- 测试存在一条 Starlette/httpx 弃用警告，不影响本轮通过。

## 尚未完成，不能宣称全部真实数据已接通

1. 来源目录仍为 33 个来源、36 个端点；本轮完成真实官方线上校准的来源数为 **0**。需要逐源提供真实原始样例、核验精确 URL 与字段映射，并由实际管理员审核。测试 Fixture 不等于实时官方数据。
2. API Key、登录业务、商业许可等限制未绕过；没有新增生产凭证。受限来源继续阻断。
3. 适配器覆盖已有 HTML/XLSX 约定结构，不是任意网页/任意文件通用解析。Fixture 标记检测是辅助规则，不能代替人工验真。复杂自然语言资格、政策适用性仍需人工判断，不猜测日期。
4. PostgreSQL、真实身份/邮件、Docker/TLS 与生产负载尚未验收。当前公开查询会读取发布快照进行动态校验，规模化性能尚未压测。
5. 新提醒为站内通知，不是短信/邮件。旧版机会入口保留；新证据发布数据从数据中心进入，未将未经校准的草稿混入旧演示机会。

下一步应关闭真实来源校准、浏览器交互和生产部署验收门禁；本版已完成核心数据流的软件链路，但不等于全部来源上线或正式发布完成。
