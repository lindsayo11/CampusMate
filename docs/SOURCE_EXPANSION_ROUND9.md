## 正文与入库验证

- 新增或恢复的 **29 个 `ready` 来源**全部在全新 SQLite 隔离库中完成官方网络采集、正文解析、证据归档和公开事项入库，得到 **29 篇真实正文、1274 条证据**。只证明这些样例及栏目链路通过，不保证同站所有文章都能解析。
- 列表、正文、支持附件继续使用严格 HTTPS、官方精确主机、公网 IP、robots、请求限速及有界队列。未猜测缺失日期，未采集用户报名、登录、验证码或私有材料。
- 为天津大学、上海财经、北京考试院、海南人社、南开就业、北交大、北大竞赛和北师大招聘校准了明确正文／标题容器。
- 采集器拒绝将网站名称当成公告标题；PDF 支持文件中的岗位表不能仅凭“硕士计划／招生学院”字样冒充招生正文。基金会的招聘公告也不因机构名含“基金会”就进入学生资助频道。

- 本轮本地验证：308 项后端测试、2 项监督器测试、22 项前端测试、TypeScript 检查和生产构建通过。新增回归覆盖网站空壳、辅助岗位表、无年份招聘通知、基金会栏目误分类、教师资格与成人教育考试，以及省级覆盖统计口径。

运行以下命令输出最新目录的完整问题清单，每个问题包含主题、地区、精确栏目、最近探测时间和失败原因：


目录现在包含中国大陆 31 个省级教育考试机构和 31 个省级人社机构的候选；通过正文验证的分别为 **16／31** 和 **21／31**。大学或城市的招聘栏目不会被用于填补省级主管机构的缺口。

优先继续补齐：

1. **省级入口**：教育考试仍缺天津、山西、内蒙古、黑龙江、上海、浙江、福建、江西、河南、湖北、湖南、四川、贵州、西藏、青海；人社仍缺河北、吉林、江西、河南、湖南、广西、海南、重庆、四川、甘肃。这里的“缺”指未通过正文验证，候选仍保留。
2. **就业与实习**：目前只有 7 个可接入来源，优先适配高校官方匿名招聘接口、实习栏目和中央企业官方招聘公告。对受登录、robots 或 HTTPS 限制的来源保留原因。
3. **高校范围**：先补当前未适配高校，再扩展其他本科、高职及科研院所；院级通知和学校级通知分别注明范围，浙江大学现有院级来源不能视作全校覆盖。
4. **栏目完整度**：同一来源继续核对历史分页、附件、不同模板、截止日期及撤回记录。当前验证以样例为依据，旧数据和已经过期的公告不等于当前可申请机会。

覆盖目标应按“地区／机构／主题／具体栏目／正文及附件／更新时效”逐项推进。未通过真实请求的候选不计入可接入名单；正式运行数量和成功率以覆盖页面的实际监测状态为准。
